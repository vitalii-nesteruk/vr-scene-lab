# VR Scene Lab — досліджуй і створюй 3D-сцени

Навчальна майстерня на A-Frame для теми «Просторова VR-сцена». Тут ти можеш додавати фігури, змінювати їхні параметри, складати власні композиції й досліджувати тіні та рух.

**[Відкрити VR Scene Lab](https://vitalii-nesteruk.github.io/vr-scene-lab/)**

Почати можна з готових куба, кулі й циліндра. Зручніше працювати на комп’ютері з мишкою. Потрібен інтернет для завантаження A-Frame; VR-гарнітура для роботи на екрані не потрібна.

## Швидкий старт

1. Обери фігуру кліком у сцені або кнопкою в списку. Рамка покаже, який об’єкт ти редагуєш.
2. Перетягни її мишкою. Змінюються x і z, а висота y зберігається. Висоту налаштуй у панелі.
3. Спробуй змінити розміри, поворот і колір. Порівнюй результат після кожної зміни.
4. Через список і «+ Додати» створи інші фігури: куб, кулю, циліндр, конус або бублик (тор).
5. Склади невелику локацію й оглянь її з різних боків.

**Зміни діють у поточній сесії браузера.** Перед перезавантаженням сторінки або відновленням початкової сцени зроби скриншот чи скопіюй потрібний код. Посилання на додаток спільне для всіх і не містить твоєї особистої композиції.

## Як керувати оглядом і фігурами

| Дія | Як виконати |
| --- | --- |
| Обрати фігуру | Клік по фігурі або її кнопці в панелі |
| Пересунути фігуру | Затисни на ній ліву кнопку миші й потягни |
| Змінити висоту | Повзунок або числове поле y |
| Скасувати поточне перетягування | Натисни Esc, поки тягнеш фігуру |
| Озирнутися | Перетягуй порожнє місце сцени |
| Перемістити камеру | Клавіші W, A, S, D, коли працюєш зі сценою |
| Повернути початковий огляд | «Скинути камеру» |
| Згорнути панель для огляду чи скриншота | «Сховати» |
| Прибрати обрану фігуру | «Прибрати фігуру» |
| Повернути початкові параметри обраної фігури | «Скинути обраний» |
| Почати сцену спочатку | «Початкова сцена» |

Прибрати можна будь-яку фігуру, навіть усі. Потім можна додати нові або відновити три стартові кнопкою «Початкова сцена». «Скинути камеру» відновлює позицію й напрямок огляду, зберігаючи твої фігури та чернетки коду.

## Що означають x, y, z

Положення задається в метрах. Повзунки x та y мають початковий діапазон −5…5 м, z — −8…8 м. Крок переміщення мишкою — 0,05 м.

- **x** — ліворуч / праворуч у початковому напрямку огляду.
- **y** — висота центра фігури. Підлога має рівень y = 0.
- **z** — глибина. За початкового огляду від’ємні z розташовані попереду камери, додатні — позаду. Щоб побачити фігуру позаду, озирнися.

Наприклад, звичайний куб висотою 1 м стоїть на підлозі при y = 0.5. При y = 0 половина куба опиниться під підлогою. Після збільшення фігури перевір, чи потрібно підняти її центр.

## Положення, поворот, розміри й масштаб

- **Положення (`position`)** визначає місце фігури.
- **Поворот (`rotation`)** задає орієнтацію за кожною віссю в градусах.
- **Розміри** задають геометрію в метрах: ширину, висоту й глибину куба; радіус кулі; радіус і висоту циліндра; радіуси основи та вершини й висоту конуса; радіус тора та його трубки.
- **Масштаб (`scale`)** множить початкові розміри. Значення 1 залишає розмір початковим, 2 збільшує вдвічі, 0.5 зменшує вдвічі.

Масштаб можна змінювати окремо за x, y, z або однаково для всіх осей. Наприклад, `scale="1 2 1"` розтягує фігуру за висотою. Поруч із повзунками є числові поля для точних значень.

## Ідеї для самостійного дослідження

Обирай те, що цікаво, і працюй у своєму темпі:

- Відсунь фігуру вглиб сцени. Чи змінився її справжній розмір або лише вигляд на екрані?
- Склади маленьку виставку, парк чи космічну станцію. Як виділити головний об’єкт кольором, розміром або розташуванням?
- Порівняй два варіанти композиції: де краще видно задум і відчувається глибина?
- Підніми фігуру над підлогою та ввімкни тіні. Що тінь допомагає помітити?
- Порівняй обертання куба й кулі без текстури. Чому рух видно по-різному?
- Зміни один параметр через HTML і знайди ту саму властивість у панелі.

Для власних нотаток зручно записувати: «Що змінив/змінила», «Що побачив/побачила», «Який висновок зробив/зробила». Можна також зберегти скриншот свого експерименту.

## Тіні й анімація

Розгорни розділ «Тіні й анімація». Початково ефекти вимкнені.

**«Тіні в усій сцені»** додає відкидання тіней фігурами та їх відображення на підлозі. Нові фігури успадковують увімкнений режим.

Анімація задається окремо для обраного об’єкта:

| Варіант | Що відбувається |
| --- | --- |
| Обертання | Повний поворот навколо y. Його найкраще видно на кубі; на кулі без текстури рух майже непомітний |
| Вгору-вниз | Підняття на 1 м і повернення |
| Пульсація | Збільшення масштабу до 125% та повернення. Зміна відбувається навколо центра, тож нижня частина може заходити під підлогу |

Повзунок тривалості задає секунди для одного проходу. Для руху вгору-вниз підйом і спуск займають по одному проходу. Зміна варіанта чи тривалості перезапускає рух. Різні фігури можуть рухатися одночасно.

«Зупинити рух» або «Без анімації» фіксує поточну позу. Клік по рухомій фігурі та зміна її положення, повороту чи масштабу також зупиняють анімацію. Якщо хочеш обрати фігуру й залишити її в русі, скористайся кнопкою в списку об’єктів. Колір і геометричні розміри можна змінювати під час руху.

«Скинути обраний» зупиняє рух і відновлює початкові параметри цієї фігури. «Початкова сцена» також вимикає тіні й усі анімації.

## Спробуй змінити HTML

У полі «HTML обраної фігури» можна редагувати параметри й натиснути «Застосувати» або ⌘/Ctrl+Enter. Наприклад, обери куб і задай:

```html
<a-box
  position="0 0.5 -4"
  rotation="0 45 0"
  scale="1 1 1"
  color="#F2766B">
</a-box>
```

Куб повернеться на 45° навколо вертикальної осі. Пропущені розміри збережуть поточні значення. Сцена та панель оновляться разом; висота поля коду підлаштується під кількість рядків.

У коді записуй координати, повороти та масштаб як три числа через пробіл. Для дробів використовуй крапку, наприклад `0.5`. Масштаб і розміри мають бути додатними; радіус вершини конуса може дорівнювати нулю.

Якщо є помилка, під редактором з’явиться пояснення. Виправ її та спробуй застосувати код ще раз. Незастосований текст зберігається окремо для кожної фігури при перемиканні вибору.

<details>

Редактор приймає один поточний тип фігури без вкладених тегів. Для іншого типу додай нову фігуру через список. Підтримано `position`, `rotation`, `scale`, `color`, геометричні розміри, `shadow` та `animation`.

- `color`: `#RRGGBB`, `#RGB` або стандартна назва на зразок `red`.
- `shadow`: `cast` і `receive` зі значеннями `true`/`false`. Щоб побачити тіні, увімкни відповідний режим усієї сцени.
- `animation`: `property` (`position`, `rotation`, `scale`), вектори `from`/`to`, додатна `dur` у мілісекундах, `loop` (`true`/`false`), `dir` (`normal`, `reverse`, `alternate`), `easing` (`linear`, `easeInOutSine`, `easeInOutQuad`, `easeInQuad`, `easeOutQuad`).

Для анімації редактор показує сталі початкові перетворення й опис руху. Після зупинки — зафіксовану позу. Застосування коду без `animation` зупиняє поточний рух; власний опис позначається в панелі як «Власна з HTML».

## Якщо працюєш із файлами на комп’ютері

Розпакуй архів так, щоб `index.html` та `dashboard.js` залишалися поруч. Відкрий `index.html` у браузері.

- `index.html` містить фігури сцени та підключення A-Frame й панелі.
- `dashboard.js` створює панель і керування. Для перших експериментів достатньо інтерфейсу та HTML фігур.

Зміни через панель автоматично у файл не записуються. Для постійної зміни можна перенести потрібні параметри в `index.html`.

За потреби запусти в цій папці локальний сервер:

```bash
python3 -m http.server 8000
```

Потім відкрий [локальний сайт](http://localhost:8000/). Інтернет усе одно потрібен для A-Frame з CDN. Адреса з `?clean=1` приховує панель і рамку вибору для чистого огляду сцени.
