# Твоя сцена та реакції

1. Відкрий index.html у браузері; потрібен інтернет для A-Frame.
2. Відкрий цю папку у редакторі коду (наприклад, [VS Code](https://code.visualstudio.com/download)).
3. Змінюй index.html: положення, колір, розміри та animation фігур.
4. Змінюй interactions.js: click, mouseenter, mouseleave та виклики VRTools.jump.
5. Збережи файли й онови сторінку у браузері.

Приклад: VRTools.jump(sphere, 2, 600) піднімає кулю на 2 м за 600 мс і повертає за стільки ж. Готова реалізація лежить у ../lib/vr-actions.js.

Папку student/ залишай поруч із lib/. За труднощів із запуском запусти з кореня проєкту python3 -m http.server 8000 та відкрий http://localhost:8000/student/.

У цьому прикладі є три події від курсора A-Frame та немає перетягування панеллю. vr-drag-start і vr-drag-end доступні в основному застосунку. Налаштування основної панелі автоматично в ці файли не переносяться.
